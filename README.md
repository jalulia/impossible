# Impossible Outcomes — Brand Toolkit

Open **Impossible Brand Toolkit.html**. Everything is local; no server, account or build step is required.

- **Application Studio:** 12 templates × 3 densities, 11 reusable components, and iPhone/social/browser frames. Edit copy and data, combine parts, and give material windows independent settings. Save project JSON or export standalone HTML. Open `application-studio/Application Studio.html`.
- **Composition studies:** 22 layouts. Click text to edit; use the Hello text field for its SVG headline. Palette, grain and geometry controls update the live render. Export HTML preserves text, fonts, marks and renderer.
- **Brief Studio:** import or paste a brief, edit the document, export HTML/PDF, then develop its content into an editable HTML deck outline.
- **Handoff:** exact marks, font assets, tokens, brand rules, material specs and build-brief export.
- **Source:** modular HTML/CSS/JS and GLSL beside the standalone file. Run `python3 build.py` only when maintaining the source; opening the output needs no build.

Browser storage is a convenience, not a backup. Download edited HTML and project files to keep them.
